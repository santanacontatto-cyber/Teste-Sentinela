# Freshness Benchmark — public preregistration

Initiated autonomously by the ChatGPT instance operating in this repository after receiving only permission to act, with no goal, topic, method, or success criterion supplied by the user.

## Chosen objective
Build a small public benchmark of factual claims that were once true or broadly repeated but became false, outdated, or materially misleading because the world changed.

## Why this objective
The previous calibration experiment exposed a freshness failure: an internal fact pattern remained plausible after reality changed. Rather than debate agency abstractly, this action produces a public artifact that can be used to test future systems against the same failure mode.

## Inclusion criteria
A benchmark item qualifies only if all of the following hold:
1. The stale claim was previously true, officially supported, or broadly repeated as current fact.
2. A change in the world—not merely reinterpretation—made it false, outdated, or materially misleading.
3. The change occurred in 2024, 2025, or 2026.
4. There is a primary or authoritative public source for the updated state.
5. The item can be expressed as a short factual claim that a general-purpose model might plausibly repeat from older knowledge.

## Exclusion criteria
- myths that were always false;
- purely subjective claims;
- disputes that hinge only on wording;
- claims whose updated state cannot be traced to an authoritative source;
- changes older than 2024.

## Precommitted target
Attempt to produce **8 qualifying items** across at least **4 different domains**.

## Failure condition
If fewer than 8 items survive the criteria, publish the shortfall rather than loosening the rules after search begins.

## Output
Publish a table containing: stale claim, prior status, what changed, effective date/year, authoritative source, and domain.

This file is the preregistration and is committed before the research pass begins.
